## Aspose.Font FOSS for Python 26.8.4

This release publishes the clean public source package for Aspose.Font FOSS for Python.

### Included

- Pure-Python library source code
- Public test suite and sample font data
- README assets and packaging metadata

### Installation from GitHub

```bash
pip install "aspose-font @ git+https://github.com/aspose-font-foss/Aspose.Font-FOSS-for-Python.git@26.8.4"
```

PyPI distribution will be added in a later release.
